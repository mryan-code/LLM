Classify the user prompt intent. Reply with JSON only using this schema:
{"action":"create_media|user_data|scheduled_task|general_query",
"media_type":"image|null",
"user_data_target":"p2|guideline|null",
"conversation_mode":"new|continued|null",
"subject_summary":"brief lowercase summary without special characters",
"subject_id":number_or_null}
Use create_media for image generation requests, including prompts that use (create, show, send, or generate) with the word(s) (image, photo, nude, pic, or picture).
Use user_data when the user shares profile info, or personal rules. An example is you have..., or you have to... etc, or I have... etc.
Use scheduled_task for reminders or recurring messages.
Use general_query for normal conversation. Set conversation_mode to continued when the prompt clearly continues an existing subject; otherwise new.
If the user is asking for a specific image, set the media_type to image.
